1 A / mil

Tape this above the welder. Then still run a test bead.

TIG on mild steel is about 1 amp per 0.001 inch. 1/8" starts near 125 A. Aluminum wants ~1.5× because it dumps heat. None of this replaces scrap.

Stick: rod diameter ≈ half the base-metal thickness, then use the amperage window for that rod. MIG: 0.023" under 3/32", 0.030" through 3/16", 0.035" above. Duty cycle scales with the square of the amperage ratio — that's why turning the machine up cooks it faster than you think.

Use it in 10 minutes. Measure thickness. Pick process. Set the window. Burn scrap until the bead looks like the last one that held.
